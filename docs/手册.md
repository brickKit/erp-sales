# erp-sales · 使用手册

## 1. 项目结构

```
erp-sales/
├── component.yaml            # 平台读的那份
├── assembly.yaml             # 只有 be-ops 读
├── buf.yaml / buf.gen.yaml   # 契约 lint / breaking-change / 代码生成配置
├── contracts/
│   ├── erp/sales/v1/sales.proto          # gRPC 契约
│   ├── sales.openapi.yaml                # HTTP 契约（对外 REST）
│   └── events/
│       └── sales.events.json
├── gen/                       # buf generate 产出，随契约提交
├── backend/
│   ├── module/module.go      # 唯一入口 New(ctx, rt)
│   ├── cmd/server/main.go    # 一行 besdk.RunStandalone(module.New)
│   └── internal/...
├── migrations/
│   ├── 001_xxx.up.sql
│   └── 001_xxx.down.sql
├── Dockerfile
├── Makefile
└── README.md
```

（详见总纲 §4 SOP-B 的标准布局）
